New scan

One per line (or comma separated): URL, IPv4/IPv6, CIDR, 1.2.3.4-9 range, or 1.2.3.* wildcard. Loading a file appends its lines; '#' comments and blanks are skipped.

Blank = common web ports.

Allow / block lists (override the target list)

One pattern per line: exact host/IP, CIDR, or *.domain / .domain suffix. Allow keeps only matches; block drops matches.

Connection overrides (pin IP / Host / SNI)

One rule per line, host:port:address. Dials the given address while keeping the URL host for Host/SNI — e.g. to reach an origin behind a CDN.

Independent of the Host header (set via the config/CLI --vhost). A name that mismatches the certificate fails verification unless “Ignore TLS errors” is on.
